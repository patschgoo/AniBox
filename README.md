# AniBox

A private, anime-focused media setup around Plex (or later Jellyfin) and an NVIDIA Shield.

## What's here

- **[library-check/](library-check/)**: AniBox Library Check. A read-only report of which seasons, OVAs,
  specials and movies are missing from your anime library in Plex, grouped by franchise, with MyAnimeList
  and AniDB links. It doesn't change anything in Plex and needs no API keys.
- **[CLAUDE.md](CLAUDE.md)**: background research and decisions (Plex vs. Jellyfin, metadata agents,
  the Jikan shutdown, Shoko, remote access).
